# SourceCraft Repo Health

Сервис оценки здоровья открытых репозиториев SourceCraft: Repo Health Score от 0 до 100
по шести категориям, объяснение оценки и приоритизированные рекомендации.

## Состав репозитория

```
frontend/   веб-интерфейс: рейтинг, страница анализа, личный кабинет, выгрузка отчётов
tools/      вспомогательные скрипты (подготовка снимка данных для демо-режима фронта)
            исходная выгрузка сборщика лежит рядом с репозиторием: ../repo_health_report.csv
docs/       сопроводительная документация
```

Разделы сборщика данных, витрины и бэкенда добавляют их владельцы — структура выше
не мешает положить их рядом (`collector/`, `backend/`).

## Запуск интерфейса

```bash
cd frontend
npm install
cp .env.example .env     # VITE_DATA_SOURCE=mock — работает без бэкенда
npm run dev              # http://localhost:5173
```

Подробности, переменные окружения и сборка образа — в [`frontend/README.md`](./frontend/README.md).

`/methodology` и берёт веса из ответа API.

## Основные сценарии

1. Открыть рейтинг, отфильтровать по языку и полноте данных, отсортировать по Score.
2. Перейти в репозиторий: итоговая оценка, категории, подтверждающие факты,
   рекомендации, сведения об отсутствии данных.
3. Выгрузить отчёт в Markdown или PDF.
4. Войти через Я ID, выбрать собственный репозиторий, запустить анализ и повторить его
   после исправлений.
